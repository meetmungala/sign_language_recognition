# PHP Backend

This module provides PHP backend services for user management, authentication, and API integration.

## Features

- User authentication and session management
- User profile management
- API integration with Python ML backend
- File upload handling
- Database operations
- Security and validation

## Structure

- `config/` - Configuration files
- `classes/` - PHP classes for database and API operations
- `api/` - API endpoints
- `auth/` - Authentication handlers
- `uploads/` - File upload directory
- `vendor/` - Composer dependencies

## Dependencies

- PHP 7.4+
- MySQL/MariaDB
- Composer
- cURL extension
- JSON extension
- PDO extension
