# React Frontend

This module provides the React.js frontend for the Sign Language Recognition Platform with 3D avatar animations.

## Features

- Real-time sign language recognition display
- 3D avatar animations using Three.js
- Interactive learning modules
- Practice tests and progress tracking
- Speech-to-sign translation
- Offline mode support
- Mobile responsive design
- Accessibility features for disabled users

## Tech Stack

- React 18
- TypeScript
- Three.js for 3D graphics
- Socket.IO for real-time communication
- Tailwind CSS for styling
- React Router for navigation
- Axios for API calls
- WebRTC for camera access

## Components

- `components/` - Reusable React components
- `pages/` - Page components
- `hooks/` - Custom React hooks
- `services/` - API and WebSocket services
- `utils/` - Utility functions
- `assets/` - Static assets and 3D models
- `styles/` - CSS and styling files

## Getting Started

1. Install dependencies: `npm install`
2. Start development server: `npm start`
3. Build for production: `npm run build`
